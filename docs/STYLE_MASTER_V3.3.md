# MOZZIPICK STYLE MASTER V3.3

Approved by KING on 2026-09-26.

This is the visual authority for all MOZZIPICK DATA LAB pages. The approved reference board contains the Home/Command dashboard, Video Script, Realtime Products, Coupang Ranking, Grade Analysis, Viral Radar, Instagram Electronics, Favorites, Production Management, Verification, Product Detail, and mobile examples.

## Global visual system
- Background: #F2F7FC
- Main panels: #FFFFFF
- Primary ink: #11264B
- Muted text: #6F7D91
- Borders: #DCE7F3
- Primary coral/orange: #FF573B / #FF4B39
- Blue: #3E80F5
- Purple: #7A59F2
- Yellow: #FFBD38
- Pink: #F55286
- Green: #22BA83
- Soft shadow: 0 4px 14px rgba(29,64,107,.055)
- UI language: dense, clean commerce dashboard; compact cards; rounded 6–12px controls; white panels on pale blue background.

## Header
Two-row header:
1. Brand/search/actions
2. Main navigation
Brand left, wide search center, command/favorites/production/profile actions right. Navigation uses icon + label with a coral active underline.

## Home
Three-column hero area:
- Large MOZZIPICK COMMAND hero
- AI search suggestions panel
- Usage examples panel
Then:
- Recommended command chip strip
- Four KPI cards
- Product card grid + command quick guide
- Additional product sections

## Route pages
Every route uses:
- Colored hero band
- Compact filter strip
- Four KPI cards
- Route-specific main content
Realtime/Coupang/Viral/Favorites/Instagram use commerce cards.
Grade uses five compact cards when desktop width allows.
Production uses a compact row/table list.
Verification uses a compact row/table list.

## Product cards
- Image on top
- Grade / hot badges on image
- Heart button at top-right
- Two-line product name
- Short description
- Coral price
- Rating/review line
- Compact metadata tags
- Two bottom actions
- Rounded 10px border, thin cool-gray outline

## Command page
Three-column workspace:
- Selected product
- Generated result / timeline
- Options
Purple/pink hero and command tabs above.

## Detail page
Compact commerce detail:
- Back + quick actions
- Large product image left
- Summary / price / metadata right
- Verification and source sections below
- External store/source buttons

## Mobile
- Same functionality as PC
- Single-column product rows with image left and content right
- Horizontal top nav remains accessible
- Fixed bottom navigation
- No feature removal; only dimensional/flow changes

## Safety rule
Do not replace this visual authority with older V3.1/V3.2 styles. Future changes should be delta edits against this master only.
