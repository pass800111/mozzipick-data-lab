창밖 규칙

거실 창: 인접 건물 일부, 아침빛, 공중교통 실루엣 정도만 침실 창: 블라인드/반투명 처리, 빛만 유입 중앙 코어/돔 전체/도시 전경은 집 안에서 공개 금지 도시 전체 공개는 대장이 집 밖으로 나간 뒤 처음 사용

🎥 오프닝 카메라 동선 — 최신 LOCK

SCENE 01 (7초, 이미지 1장): 대장 등장 금지. 거실/작업실의 오른쪽 끝에서 시작 → 천천히 좌측으로 이동 → 장비 케이스 → 메달/사진 → 통신기/태블릿 → 침실로 이어지는 문/통로까지 접근. 카메라는 ‘이 집의 주인이 어떤 인물인지’ 소품으로 먼저 소개한다. SCENE 02 (6초, 이미지 1~2장): 카메라가 침실 문턱을 통과 → 침실 내부를 천천히 훑음 → 후반 2~3초에 처음으로 침대에서 자고 있는 대장이 프레임에 들어온다. 알람은 아직 울리지 않음. SCENE 03 (4초, 이미지 1장): 알람 06:59 → 07:00. 알람이 울리고 대장이 화들짝 깨어남. SCENE 04 (7초, 이미지 2장): 황급히 출근 준비. 기존 MASTER 캐릭터/소품 유지. SCENE 05 (5초, 이미지 1장): 현관문을 열고 밖으로 나감. SCENE 06 (7~8초, 이미지 2장): 대장이 외부 보행로에 나오는 순간 카메라가 뒤/위로 크게 빠지며 처음으로 돔 전체 + 중앙 코어 + 도시를 공개.
