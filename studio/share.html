📲 프로젝트 공유 / 백업

PC와 핸드폰 사이에서 KEY WORLD 프로젝트 전체 데이터를 옮깁니다.

작업실로드맵

현재 이 기기에 저장된 데이터

1. PC에서 내보내기 / 핸드폰으로 보내기

체크리스트, 제작 로드맵, 스토리보드, 메모 등 이 브라우저에 저장된 AI 영상 제작소 데이터를 하나의 JSON 백업 파일로 만듭니다.

핸드폰의 공유 기능이 지원되면 카카오톡·Quick Share·메일·Drive 등 설치된 공유 대상으로 보낼 수 있습니다. 지원되지 않으면 백업 파일 저장을 사용하세요.

2. 핸드폰 / 다른 PC에서 불러오기

받은 .json 백업 파일을 선택하세요. 기존 데이터가 있는 경우 안전을 위해 먼저 확인을 받습니다.

3. 파일 대신 코드로 불러오기

파일 전달이 불편하면 PC에서 `백업 코드 복사` 후 메시지나 메모앱으로 보내고, 핸드폰에서 아래 칸에 붙여넣으면 됩니다.

사용 순서

① PC에서 이 페이지 열기 → 바로 공유 또는 백업 파일 저장
② 핸드폰에서 같은 사이트의 이 페이지 열기
③ 받은 JSON 파일을 불러오기
④ 이후 작업실 / 제작 로드맵을 열면 같은 프로젝트 내용이 표시됩니다.
